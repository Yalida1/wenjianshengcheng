# 管理员指南

系统管理员维护组织用户、启停账号、角色权限、项目成员和审计日志；模板管理员维护模板、DOCX 源文件、章节、变量、版本、有效期和 Format Profile。权限变更和模板发布均会审计。

首次启动由种子创建 Demo 组织、五类角色、权限、管理员、字段字典、Format Profile 和明确标注的 Demo 模板。本机开发默认登录账号为 `admin`、密码为 `admin123`，可通过 `DEMO_ADMIN_ACCOUNT` 和 `DEMO_ADMIN_PASSWORD` 修改。生产前必须改为至少 12 位的独立强密码、停用不需要的 Demo 账号、导入客户模板、配置组织范围并复核字段/规则。

排障先查 `/ready`、容器状态、API request id、作业事件和审计日志。禁止直接修改已发布模板版本、已确认字段或已定稿文档；应创建新版本/修订。备份恢复、升级和密钥轮换按运维与部署文档执行。
