# 产品说明

## 目标与角色

平台把需求材料、项目建议书、可研、招标文件和合同串成可追溯的版本链。角色包括系统管理员、模板管理员、项目编制人员、审核人员和只读人员；后端执行组织、角色、权限、项目成员和对象级访问控制。

## 标准流程

每一阶段依次完成来源选择、上传/选取、解析、字段提取、证据确认、模板选择、异步生成、预览编辑、规则校验、版本对比、人工定稿和导出。定稿版本不可变，后续修改产生新修订草稿；上游变更只标记下游过期，不静默覆盖。

## 业务边界

本期没有独立评标、中标、评委、供应商、履约台账和自动发布模块。招标模板中的评标办法只是文档章节。可研总投资、招标预算/最高限价、最终合同金额相互独立；项目总周期与单份合同期限、项目全部范围与采购/合同范围也不得自动映射。

## 合同门禁

合同付款节点必须有触发条件，比例合计为 100%，金额合计等于最终合同金额。乙方、最终合同金额、税率或付款计划缺失时只能形成预草案；满足证据、确认和校验门禁后才可形成签约准备版。
