# 用户指南

登录后先在项目空间新建项目，进入阶段卡片。需求阶段可上传需求材料；可研、招标和合同阶段可从“来源”选择上一阶段已定稿文件，或上传已有文件。等待解析完成后查看字段与原文证据，对 P0 字段逐项确认或解决冲突。

系统管理员可在项目卡片选择“删除项目”。删除前必须输入完整项目编号；确认后，项目记录、四阶段数据、上传文件、解析结果、字段证据、生成记录、定稿文档和导出文件将一并永久删除。若项目仍有后台任务运行，系统会阻止删除并提示稍后重试。

选择当前有效模板，启动生成并查看步骤/事件。进入文档工作台审核内容、编辑允许修改的块、保存 revision、处理批注和校验问题；固定模板块不能直接改。P0 清零且人工审阅完成后定稿。定稿后可导出 DOCX/PDF，修改需“创建修订”，不会覆盖原正式版。

合同页面使用付款计划表维护节点、比例、金额和触发条件；合计必须同时满足 100% 和最终合同金额。页面提示无权限、来源变更或并发冲突时，应刷新数据并按提示选择保留旧来源或创建新草稿。
