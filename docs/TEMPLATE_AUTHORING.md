# 模板制作指南

模板管理员在模板中心创建元数据，上传真实 DOCX 源文件，执行预检后维护章节和变量，再发布版本。模板应明确阶段、专业、采购/合同类型、组织范围、生效/失效日期、固定/可编辑/条件章节和 Format Profile。

变量使用 `{{ field_key }}`，必须与字段字典键一致；发布前检查变量是否已定义、必需章节是否存在、文件是否为有效 OOXML、固定条款是否锁定。发布后的版本不可覆盖，变更时创建新版本。普通用户只会看到当前有效、组织适用、阶段适用且业务类型匹配的模板。

模板来源必须选择以下一类：国家正式文本、依据正式大纲适配、平台参考模板、其他正式模板。国家正式文本由平台维护权威来源链接并设置为只读、不可生成；大纲适配模板必须登记发布机关和官方来源链接，并在页面及 DOCX 中声明“不是官方原文”；平台参考模板不得宣称符合主管部门或客户制度；客户、行业或地区正式模板归入其他正式模板并保留确认单位和依据。客户模板导入后应逐项校准章节、字段、格式、字体和校验规则，并重新执行 Golden Case。
