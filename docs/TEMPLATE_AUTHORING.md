# 模板制作指南

模板管理员在模板中心创建元数据，上传真实 DOCX 源文件，执行预检后维护章节和变量，再发布版本。模板应明确阶段、专业、采购/合同类型、组织范围、生效/失效日期、固定/可编辑/条件章节和 Format Profile。

变量使用 `{{ field_key }}`，必须与字段字典键一致；发布前检查变量是否已定义、必需章节是否存在、文件是否为有效 OOXML、固定条款是否锁定。发布后的版本不可覆盖，变更时创建新版本。普通用户只会看到当前有效、组织适用、阶段适用且业务类型匹配的模板。

模板来源必须选择以下一类：国家正式文本、依据正式大纲适配、平台参考模板、其他正式模板。国家正式文本由平台维护权威来源链接并设置为只读、不可生成；大纲适配模板必须登记发布机关和官方来源链接，并在页面及 DOCX 中声明“不是官方原文”；平台参考模板不得宣称符合主管部门或客户制度；客户、行业或地区正式模板归入其他正式模板并保留确认单位和依据。客户模板导入后应逐项校准章节、字段、格式、字体和校验规则，并重新执行 Golden Case。

## 从成品文件提取候选模板

模板管理员可以在模板中心上传一份已完成的 DOCX，采用以下流程生成可继续编辑的候选模板：

1. 程序解析完整文件结构，记录段落、表格、标题样式、分节、页眉页脚和原始版式信息。
2. 管理员明确勾选外部模型处理授权后，系统才会把文件中的文本块发送给已配置的小模型；未授权时请求被阻止。
3. 小模型识别可能的章节和变量，程序再次校验来源块、逐字证据、数据结构并去重。无法回指原文的候选不会保留。
4. 管理员逐项勾选章节和变量，补充模板名称、来源分类和必要的来源依据，再确认建立模板草稿。
5. 系统基于原 DOCX 保留样式与页面设置，清除成品文件中的具体项目正文、页眉页脚和文档元数据，写入模板占位符并执行预检。
6. 草稿仍须人工校准章节顺序、变量键、表格、字体、固定条款和 Format Profile，随后通过原有发布门禁手工发布。

当前反向提取仅接收 DOCX。PDF、扫描件和 OCR 结果不能可靠保留 Word 样式、表格结构和分页，因此不会伪装成“等价模板”；如只有 PDF，应先获得可编辑源文件或由人工整理为 DOCX。国家正式文本不能通过该入口新增，避免把二次文件误登记为国家官方原文。
